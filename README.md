# Terra Twins

A simple responsive video-streaming website starter with a Terra Twins header.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `app.js` — local video preview and search

## Run it
Open `index.html` in a browser, or upload these files to a GitHub repository and enable GitHub Pages.

## Important limitation
This starter only previews videos selected on the current device/browser. It does **not** upload videos to a shared server, create accounts, or publish videos for other users. GitHub Pages hosts static files; to make community uploads work, add a backend API and video/object storage with authentication, upload limits, and moderation. Never put private API keys or server secrets in frontend JavaScript.
